# Escopo e limites

## Contexto

Projeto de portfólio sobre automação de consultas de consórcios com Python e Playwright. A documentação inicial foi organizada sem acesso ao código original ou a registros de execução.

## Escopo público atual

- Apresentação do problema e do objetivo.
- Proposta de organização para uma futura demonstração.
- Critérios para revisar código, dados e evidências antes de publicar.

## Fora do escopo público

- Credenciais, tokens e mecanismos de autenticação de ambientes privados.
- Dados de clientes, contratos, documentos, saldos e resultados de consultas reais.
- Identificação de empresas, portais internos e regras de negócio confidenciais.
- Código original que ainda não tenha sido fornecido e autorizado para compartilhamento.

## Informações a confirmar com o código original

- Entradas e saídas efetivamente utilizadas.
- Etapas já implementadas, tratamento de erros e dependências.
- Limitações operacionais e permissões do ambiente.
- Critérios e evidências para qualquer resultado quantitativo.

Nenhuma funcionalidade ou resultado deve ser tratado como comprovado apenas por constar desta documentação inicial.
